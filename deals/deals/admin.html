Add Breadfast

Breadfast's prices exist only inside its app. Record the app once on your phone, upload the recording here, and the site keeps Breadfast's prices fresh by itself until the app signs you out.

1. Record the app

Android (with a computer, about 30–45 minutes the first time)
  1. A normal Android phone hides apps' encrypted traffic, so this runs Breadfast in an Android emulator on your computer. Install Android Studio (free). Open Device Manager › Create device, pick a phone (e.g. Pixel 7), then a system image whose target says "Google APIs", not "Google Play" (only those let the recorder install its certificate). Start it.
  2. Get Breadfast's APK on the computer, for example from APKMirror (com.breadfast), and drag it onto the emulator window to install it. If it comes as a bundle (.apkm/.xapk), use that site's installer app in the emulator.
  3. Install HTTP Toolkit (free) on the computer, click "Android device via ADB" and accept the prompts in the emulator. It now records the emulator's traffic.
  4. In the emulator, open Breadfast, sign in, set your delivery address (the emulator's ⋯ › Location can place you in Cairo), and open a few categories, scrolling a little in each.
  5. In HTTP Toolkit, filter by breadfast. Either export everything as HAR and upload it below, or (works on the free plan) click one request that loads a category's products, choose Export › cURL, and paste it in the second box below. Add a few categories that way.
iPhone
  1. Install Proxyman from the App Store and follow its setup: it installs a VPN profile and a certificate. Then trust that certificate in Settings › General › About › Certificate Trust Settings.
  2. Start recording in Proxyman, and turn on decryption (SSL proxying) for Breadfast's addresses when it offers.
  3. Open Breadfast and go through the categories you care about, scrolling a little in each.
  4. Back in Proxyman, export the Breadfast requests as HAR (or copy one as cURL for the second box).

If the recorder shows Breadfast's requests as failed or "certificate rejected", the app blocks recording, and this route won't work.

2. Upload it

Not sure? Leave pounds, check the prices shown after the upload, and upload again with piasters if they're 100× too big.

…or paste one request

A request that loads a category's products, copied as cURL. The site sends it once to read the products, then keeps refreshing it. Add as many categories as you like, one at a time. Uses the token and price unit above.

See Breadfast on the site →

The recording holds your Breadfast session. The site reads it, keeps only what it needs to refresh prices (on its private storage), and deletes the file straight away. It only ever repeats product-list requests, never anything touching your cart, orders, payment, address or account.
